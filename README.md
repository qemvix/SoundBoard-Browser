# SoundBoard-Browser
This is the SoundBoard Browser.  It is a app that i made that is basically a browser window with a input mic select, and a virtual mic output select. any music or sounds that come from that browser window, will come through your mic. works with anything as long as you can change your input mic device. requires WebView2 Runtime and VB-Audio Cable.
